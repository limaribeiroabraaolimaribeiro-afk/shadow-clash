# Shadow Clash

Protótipo de jogo de luta 2.5D em Three.js, com personagens 3D procedurais e animações por esqueleto.

## Como jogar

Abra `index.html` em um servidor HTTP local (ex.: `python3 -m http.server 8000`). O Three.js é carregado pela internet.

| Tecla | Comando |
| --- | --- |
| A/D, ←/→ | Movimentar |
| W/↑ | Saltar |
| S/↓ | Agachar |
| J | Jab |
| K | Soco pesado |
| H | Gancho |
| L | Chute baixo |
| O | Chute alto |
| I | Defender |
| U | Especial |
| R | Reiniciar |

Inclui controles para dispositivos móveis. Este é um protótipo técnico: o modelo definitivo do lutador precisa ser produzido em GLB com rig humanoide.
